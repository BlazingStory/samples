# BlazingStory Multi-Branch Application Demo

## Overview

This project demonstrates how to host **Blazing Story** on a subpath (`/stories`) alongside a main Blazor application on the root path (`/`) within a single ASP.NET Core application using multi-branch architecture.

## Running the Application

```bash
dotnet run
```

### Access the application

- Main app: `http://localhost:5020/`
- Blazing Story: `http://localhost:5020/stories`
